Requisitos previos

  • Una cuenta de Google (te sirve la de Gmail).
  • Un navegador actualizado en ordenador: Chrome, Edge, Firefox o Safari recientes. En móvil también funciona, pero algunas pantallas de Apps Script son incómodas en teléfono.
  • Una imagen de inspiración descargada o copiada de Pinterest.
  • Un número de WhatsApp con código de país, por ejemplo +5215512345678.

Conceptos fundamentales y arquitectura

Antes de tocar ninguna herramienta, entiende qué piezas forman el sistema. No hace falta memorizar nada: vuelve a esta pestaña cada vez que un término te bloquee.

¿Qué es un catálogo estilo Instagram?

Un catálogo estilo Instagram es una aplicación web interactiva que presenta tus productos o servicios con el formato visual, dinámico y atractivo de la red social Instagram: cabecera de perfil, feed en cuadrícula o tarjetas, carrusel de fotografías, botones de «me gusta» y comentarios.

Pero además incorpora funciones de comercio:

  • una bolsa de pedidos (carrito de compras);
  • envío del pedido estructurado a WhatsApp;
  • exportación del catálogo completo a PDF.

Construirlo «con Gemini» significa que no vas a escribir código manualmente. La inteligencia artificial redacta tanto la lógica del servidor (backend) como el diseño de la interfaz visual (frontend) a partir de prompts e imágenes de ejemplo.

Idea clave: tú aportas las decisiones (qué vender, qué diseño te gusta, qué datos hay en la hoja) y la IA aporta el código. Tú copias, pegas y verificas.

¿Para qué sirve y por qué es importante?

Las páginas web tradicionales de comercio electrónico resultan frías, complejas y costosas de mantener. Vender únicamente por Instagram implica responder mensajes uno a uno, enviar listas desactualizadas y perder ventas por falta de inmediatez.

Este sistema resuelve ambos problemas:

  • Cero coste de desarrollo y mantenimiento: no requiere servidores, hosting, dominios ni programadores, según la fuente.
  • Experiencia familiar para el cliente: navega por una interfaz parecida a Instagram, lo que genera confianza e inmediatez.
  • Gestión sencilla desde Google Sheets: actualizas precios, nombres, promociones y fotos desde la hoja de cálculo, incluso desde el teléfono.
  • Conversión directa por WhatsApp: el cliente arma el pedido en la web y al hacer clic se abre su WhatsApp con el desglose exacto de productos, cantidades y total.

Aplicaciones y situaciones reales de uso

Restaurantes, cafeterías y repostería

Menú digital interactivo con fotos atractivas de platillos, carruseles para mostrar ingredientes y pedidos directos a cocina por WhatsApp.

Tiendas de moda, ropa y calzado

Muestrario tipo perfil de Instagram con etiquetas de oferta, tallas, colores y fotos desde distintos ángulos.

Artesanías, joyería y regalos

Muestrario de piezas únicas con botones de «me gusta» para medir popularidad antes de producir en masa.

Servicios profesionales

Estética, consultoría o cursos: catálogo visual con descripción detallada, precios y enlace de reserva por chat.

Los tres componentes del sistema

Para construir este catálogo sin programar vas a unir tres piezas gratuitas que se comunican entre sí:

  1. El Backend (el cerebro y la base de datos). Es la parte invisible que guarda la información. Usarás Google Sheets como base de datos (precios, títulos, fotos) y Google Apps Script (un entorno de código de servidor gratuito de Google) para enviar esa información a la web.
  2. El Frontend (la cara visible). Es la página web interactiva que ve tu cliente. Se diseña y genera en Google AI Studio combinando el Prompt N.º 2 y una imagen de inspiración.
  3. El Conector (URL Exec / API). Es una dirección web especial que conecta el backend con el frontend: cuando cambias un precio en la hoja, la web lo refleja al actualizar.

Términos técnicos clave, explicados sin jerga

  • Prompt: instrucción escrita en lenguaje cotidiano que le das a la IA para que realice una tarea técnica.
  • API (Interfaz de Programación de Aplicaciones): el «puente» que permite que la página web lea los datos guardados en tu Google Sheets.
  • URL Exec: la dirección web única generada por Google Apps Script al publicar tu backend. Debe terminar en /exec.
  • Seguridad Hash: método para resguardar contraseñas transformándolas en una cadena protegida de texto, de modo que nadie pueda leer las claves originales en la hoja de cálculo.
  • No-Code / Low-Code: metodología de creación de software que minimiza o elimina la necesidad de escribir código manualmente.
  • Responsive: diseño web adaptable que se ajusta a la pantalla de cualquier dispositivo, incluido el móvil.
  • Backend y Frontend: el backend es la parte que guarda y procesa datos; el frontend es lo que el usuario ve y toca.

Ejemplo correcto y ejemplo incorrecto

Ejemplo CORRECTO: configurar Google Sheets con las pestañas «Productos», «Categorías», «Usuarios» y «Ajustes», vinculadas mediante un Apps Script publicado con acceso «Cualquiera».

Ejemplo INCORRECTO: intentar conectar Google AI Studio directamente a una hoja de Sheets privada sin publicar el Apps Script como aplicación web con URL Exec. La web no cargará los datos.

La diferencia entre ambos casos es una sola decisión: el permiso de acceso de la implementación de Apps Script. Si lo dejas en «Solo yo», tu catálogo funcionará únicamente cuando tú estés conectado con tu cuenta de Google.

Resumen de la pestaña

Un catálogo estilo Instagram combina tres piezas: una base de datos sencilla (Google Sheets), un servidor gratuito que la expone como API (Google Apps Script) y una interfaz generada por IA (Google AI Studio + Gemini). El pegamento entre las piezas es la URL Exec. Si entiendes esas cuatro ideas, estás listo para el procedimiento.

Procedimiento completo, fase a fase

Cada paso indica una única acción principal, el motivo por el que se hace y el resultado que deberías ver. Si algo no coincide, consulta la pestaña Errores.

Fase 1 · Paso 1: elige un diseño de referencia en Pinterest

Objetivo: conseguir una imagen que Gemini pueda imitar en estructura, colores y disposición de tarjetas.

Gemini es multimodal: no solo lee texto, también analiza imágenes. Al entregarle una captura de un diseño que te guste, imitará su estructura de colores, la disposición de las tarjetas y la estética general.

  1. Ingresa a Pinterest. Abre Pinterest en el navegador y asegúrate de haber iniciado sesión o de poder navegar por la búsqueda pública. Pinterest es la fuente de inspiración visual del flujo de trabajo descrito.
  2. Busca referencias. En la barra de búsqueda escribe términos como ui instagram profile shop design, app catalog layout o grid product card ui. Los términos en inglés devuelven más resultados de diseño de interfaz.
  3. Selecciona un diseño con la estructura que deseas: fotos cuadradas, botones redondeados, cabecera limpia con foto de perfil. Cuanto más clara sea la referencia, más fiel será el resultado generado.
  4. Copia o descarga la imagen. Haz clic derecho sobre la imagen elegida y selecciona «Copiar imagen», o descárgala en formato JPG/PNG. La imagen se adjuntará al prompt del frontend.

Resultado esperado: tienes una imagen de referencia en el portapapeles o un archivo JPG/PNG en tu equipo.

Si algo falla: si el clic derecho está deshabilitado, usa una captura de pantalla del diseño. Si la imagen pesa más de 2 MB, recórtala o redúcela antes de usarla: la compilación en AI Studio puede ralentizarse.

Resumen del paso: una buena imagen de referencia ahorra decenas de instrucciones de texto.

Fase 1 · Paso 2: prepara la carpeta y la hoja de cálculo

Objetivo: tener un lugar único donde vivirán la base de datos y, más adelante, las fotos de los productos.

  1. Entra a Google Drive con tu cuenta de Google. Drive es el almacenamiento donde se guardarán la hoja y las imágenes.
  2. Crea una carpeta nueva. Haz clic en «Nuevo» > «Carpeta nueva» y nómbrala Catálogos Studio AI. Mantener todo junto facilita encontrar los archivos y otorgar permisos.
  3. Entra en la carpeta creada. Haz clic en «Nuevo» > «Hoja de cálculo de Google» y nómbrala Base_de_Datos_Catálogo. Esta hoja será la base de datos real del catálogo.

Resultado esperado: dentro de la carpeta Catálogos Studio AI tienes una hoja de cálculo llamada Base_de_Datos_Catálogo, abierta o accesible desde Drive.

Si algo falla: si no ves la opción «Hoja de cálculo de Google», comprueba que estás dentro de la carpeta y no en la vista general de Drive.

Fase 2 · Paso 1: obtén el código del backend con Gemini (Prompt N.º 1)

Objetivo: conseguir un bloque de código completo para Google Apps Script, adaptado a tu tipo de negocio.

  1. Abre Gemini o Google AI Studio. Ambos permiten conversar con el modelo y copiar el código generado.
  2. Copia la plantilla del Prompt N.º 1 que tienes más abajo. La plantilla concentra los requisitos que el backend debe cumplir.
  3. Rellena el campo personalizable con tu tipo de negocio: por ejemplo comida para restaurante, tienda de ropa femenina o repostería artesanal. El modelo adapta nombres de campos y ejemplos a tu nicho.
  4. Envía el prompt. Gemini procesará la solicitud y te entregará un bloque de código para Apps Script. Ese bloque es el que pegarás en la hoja de cálculo.
  5. Pulsa «Copiar código» en el bloque generado. Copiar desde el botón evita arrastrar formato o cortar líneas.

Resumen del paso: el prompt correcto describe la estructura de datos y las funciones; no hace falta que tú sepas programarlas.

Fase 2 · Paso 2: instala el código en Google Apps Script

Objetivo: pegar el código generado dentro del editor que está vinculado a tu hoja de cálculo.

  1. Abre tu hoja Base_de_Datos_Catálogo en Google Sheets. Apps Script debe abrirse desde la hoja para quedar vinculado a ella.
  2. Ve a «Extensiones» > «Apps Script». Se abrirá el editor de código asociado a esta hoja.
  3. Borra todo el código por defecto que aparece, normalmente function myFunction() { ... }. Si dejas ese código, el proyecto tendrá funciones que no necesitas.
  4. Pega el código completo que copiaste de Gemini. Es la lógica del backend y las funciones de inicialización.
  5. Guarda el proyecto con el icono del disco en la barra superior del editor. Los cambios no se ejecutan si no se guardan.

La fuente muestra este fragmento como ejemplo parcial del código que genera Gemini. No lo uses solo: es una muestra, no el backend completo.

function doGet(e) {
  return ContentService.createTextOutput(JSON.stringify(obtenerDatos()))
    .setMimeType(ContentService.MimeType.JSON);
}

function inicializarBaseDeDatos() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  crearHojaSiNoExiste(ss, "Productos");
  crearHojaSiNoExiste(ss, "Categorías");
  crearHojaSiNoExiste(ss, "Usuarios");
  crearHojaSiNoExiste(ss, "Ajustes");
}

Resultado esperado: el editor muestra tu código guardado, sin errores de sintaxis visibles y con un nombre de proyecto propio.

Si algo falla: si al guardar aparece un error de sintaxis, es probable que el copiado se haya cortado. Vuelve a copiar desde el botón del bloque de Gemini y reemplaza todo el contenido del editor.

Fase 2 · Paso 3: crea las tablas automáticamente

Objetivo: que la hoja de cálculo se rellene sola con las pestañas y columnas necesarias.

  1. En la barra superior de Apps Script, abre el menú de funciones junto a «Depurar». Ahí se elige qué función ejecutar.
  2. Selecciona inicializarBaseDeDatos (o el nombre de la función de configuración inicial que haya generado Gemini). Es la función que crea las pestañas y encabezados.
  3. Haz clic en «Ejecutar». Se iniciará el proceso de creación de la estructura.
  4. Autoriza los permisos. Aparecerá una ventana de seguridad: pulsa «Revisar permisos», elige tu cuenta de Google, entra en «Configuración avanzada» (en letras pequeñas abajo), pulsa «Ir a Proyecto sin título (no seguro)» y finalmente «Permitir». Google pide confirmación porque el script accede a tus hojas y a tu Drive.
  5. Vuelve a la hoja de cálculo y comprueba las pestañas creadas. Así verificas que la inicialización terminó correctamente.

Resultado esperado: la hoja contiene estas cuatro pestañas con sus columnas:

  • Productos: ID, Nombre, Descripción, Precio Regular, Precio Promo, Categoría, Foto PNG, Carrusel, Destacado, Etiqueta Promo y Validez.
  • Categorías: para organizar tus secciones (bebidas, platos fuertes, postres…).
  • Usuarios: para gestionar el acceso administrativo con credenciales protegidas.
  • Ajustes: nombre del negocio, biografía, teléfono de WhatsApp, logo, foto de portada, colores y tipografía.

No borres ni reordenes las columnas generadas. Alterar los encabezados rompe la conexión con la API y la web dejará de mostrar los datos correctamente.

Si algo falla: si no aparecen las pestañas, vuelve a ejecutar la función y revisa que hayas autorizado los permisos. Si ves un error de función no encontrada, el código pegado está incompleto.

Fase 2 · Paso 4: publica el backend y copia la URL Exec

Objetivo: convertir tu hoja de cálculo en una API accesible desde la web.

  1. En la esquina superior derecha del editor de Apps Script, pulsa «Implementar» > «Nueva implementación». La implementación es lo que publica el script como servicio web.
  2. Pulsa el icono de engranaje junto a «Seleccionar tipo» y elige «Aplicación web». Necesitamos una URL pública, no una ejecución manual.
  3. Rellena los campos: descripción Backend API Catálogo v1; «Ejecutar como»: Yo (tu correo de Google); «Quién tiene acceso»: Cualquiera. Si eliges «Solo yo», la página web no podrá leer los productos.
  4. Pulsa «Implementar». Google generará la dirección del servicio.
  5. Concede los permisos de autorización de nuevo si el sistema lo solicita. La publicación requiere confirmar el acceso por segunda vez en algunos casos.
  6. Copia la URL de la aplicación web (debe terminar en /exec) y guárdala en un bloc de notas. La necesitarás en el prompt del frontend.

Resultado esperado: tienes una URL parecida a https://script.google.com/macros/s/XXXXXXXX/exec. Si la pegas en una pestaña nueva del navegador, debería devolver una respuesta en formato JSON.

El paso más crítico de todo el tutorial: el acceso debe ser «Cualquiera». Es la causa número uno de catálogos que cargan vacíos.

Fase 3 · Paso 1: prepara Google AI Studio

Objetivo: abrir un espacio de trabajo donde generar la interfaz.

  1. Ingresa a Google AI Studio en aistudio.google.com. Es el entorno donde se genera y compila el frontend.
  2. Inicia sesión con tu cuenta de Google y pulsa «Get Started». El acceso requiere una cuenta de Google activa.
  3. Abre un nuevo espacio de trabajo («Create New Prompt»). Cada espacio conserva su propio prompt e imagen adjunta.
  4. Selecciona un modelo con capacidad de razonamiento visual, por ejemplo el que la fuente llama Gemini 3.8 Flash o la versión equivalente disponible en tu interfaz. Necesitas un modelo que entienda la imagen de referencia y genere código web.

Resultado esperado: ves la caja de texto del prompt, el selector de modelo y el botón para ejecutar.

Fase 3 · Paso 2: inserta la URL Exec y la imagen de inspiración (Prompt N.º 2)

Objetivo: dar al modelo el diseño visual y la dirección de los datos.

  1. Copia la plantilla del Prompt N.º 2. Contiene la descripción funcional que debe cumplir la aplicación.
  2. Pega el prompt en la caja de texto de Google AI Studio. El prompt es la instrucción principal del proyecto.
  3. Sustituye el marcador PEGA_AQUI_TU_URL_EXEC por tu URL de backend terminada en /exec. Sin la URL, la interfaz no sabrá de dónde leer los productos.
  4. Adjunta la imagen de inspiración pegándola con Ctrl + V o usando el botón de adjuntar imagen. El modelo imitará la estructura visual de la referencia.
  5. Pulsa «Run» / «Create». Comenzará el proceso de compilación de la aplicación.

Fase 3 · Paso 3: revisa la aplicación generada

Objetivo: comprobar que la interfaz incluye todo lo prometido antes de cargar datos reales.

Al finalizar, verás una vista previa en vivo del catálogo. Comprueba que aparecen estos componentes:

  • Cabecera de perfil: foto de perfil, nombre del negocio, biografía y botones de interacción.
  • Feed en cuadrícula y tarjetas: muestrario de productos con precio, foto principal y etiquetas de oferta.
  • Modal de detalle: al hacer clic en un producto se abre una ventana con carrusel de imágenes, descripción completa, me gusta y comentarios.
  • Bolsa de pedidos (carrito): contador flotante que acumula selecciones y calcula el total.
  • Botón de WhatsApp: envía la lista formateada del pedido al número configurado.
  • Exportador a PDF: botón de descarga o impresión del catálogo estructurado.
  • Panel de administración: inicio de sesión administrativo para gestionar productos sin tocar código.

Resultado esperado: todos los componentes anteriores están presentes y responden a los clics.

Si algo falla: si falta alguno, pide una corrección en el mismo espacio de AI Studio indicando exactamente qué componente falta. Si la web aparece vacía, revisa la URL Exec y el permiso «Cualquiera».

Fase 4 · Paso 1: primer acceso al panel de administración

Objetivo: crear el usuario administrador que gestionará la tienda.

  1. En tu catálogo generado, pulsa «Administrar» o navega a la sección de inicio de sesión. El panel es donde se cargan los productos y ajustes.
  2. Registra el primer usuario. Como la tabla «Usuarios» está vacía, el sistema te pedirá nombre, correo y contraseña segura. El primer usuario es el administrador.
  3. Pulsa «Registrar Usuario». Se guardarán las credenciales en la hoja de cálculo.
  4. Revisa la pestaña «Usuarios» en Google Sheets. Verás que la contraseña aparece resguardada mediante hash, no en texto legible. Esto confirma que la protección está funcionando.

No olvides tus credenciales de administración. Recuperarlas puede requerir reiniciar la tabla de Usuarios desde Apps Script.

Fase 4 · Paso 2: personaliza la identidad visual

Objetivo: que el catálogo tenga la apariencia de tu marca.

Dentro del panel de administración, ve a la pestaña Ajustes y completa:

  • Nombre del negocio: la marca de tu empresa.
  • Biografía: descripción corta estilo Instagram, por ejemplo comida artesanal | envío a domicilio | pedidos aquí.
  • Logotipo y portada: imágenes principales; se guardan automáticamente en tu Google Drive.
  • Tipografía: fuentes modernas como Poppins o Space Grotesk, según la fuente.
  • Colores de marca: define el color primario (por ejemplo, rosa Instagram o dorado).
  • Número de WhatsApp: con código de país, sin guiones ni espacios.

Pulsa «Guardar Ajustes» al terminar. Los cambios se escriben en la pestaña «Ajustes» de la hoja.

Resultado esperado: la cabecera del catálogo muestra el nombre, la biografía, el logo y los colores elegidos.

Fase 4 · Paso 3: carga categorías y productos

Objetivo: llenar el catálogo con contenido real.

Crear categorías

  1. Ve a «Categorías» > «Nueva Categoría». Las categorías organizan el feed y los filtros.
  2. Agrega nombres como Platos Fuertes, Bebidas o Postres. Nombres claros facilitan la navegación del cliente.
  3. Sube una imagen representativa para cada categoría. La portada de categoría mejora la experiencia visual.

Cargar productos

  1. Ve a «Productos» > «Nuevo Producto». Aquí se rellena la ficha que verá el cliente.
  2. Completa el formulario: nombre, precio regular y precio promo, categoría, foto principal en PNG (preferiblemente sin fondo), carrusel de hasta 4 fotos secundarias, casilla «Destacado», etiqueta promo (por ejemplo 20% OFF Hoy) y fecha de validez. Cada campo alimenta una columna de la hoja «Productos».
  3. Pulsa «Guardar Producto». La información se envía a tu Google Sheets.

Resultado esperado: el producto aparece en la hoja «Productos» y, al refrescar el catálogo, se muestra en el feed con su precio, foto y etiqueta.

Si algo falla: si el producto no aparece, comprueba que guardaste y que la URL Exec sigue publicada con acceso «Cualquiera».

Fase 5 · Paso 1: publica el catálogo en la web

Objetivo: obtener un enlace público que puedas compartir con tus clientes.

  1. En la esquina superior derecha de Google AI Studio, pulsa «Publish». Es el mecanismo de publicación directa que describe la fuente.
  2. Escribe el subdominio gratuito que deseas, por ejemplo mitienda.studios.app. Será la dirección pública de tu catálogo.
  3. Respeta las reglas del subdominio: entre 6 y 63 caracteres, solo letras minúsculas y números, y debe comenzar y terminar con letra o número. Si no cumple las reglas, la publicación será rechazada.
  4. Pulsa «Publish Application». El catálogo queda accesible desde cualquier teléfono o computadora.

Resultado esperado: tu catálogo se abre en el subdominio asignado y es navegable desde el móvil.

La fuente indica que la publicación se hace con un subdominio gratuito de AI Studio. Si tu interfaz no muestra esa opción, usa la alternativa de la siguiente tarjeta.

Fase 5 · Paso 2 (alternativa): GitHub + Netlify / Vercel

Objetivo: publicar con tu propio dominio si la publicación directa no está disponible o quieres más control.

  1. Exporta el código fuente (HTML/JS/CSS) desde Google AI Studio. Necesitas los archivos para subirlos a un repositorio.
  2. Sube el código a un repositorio en GitHub. GitHub actúa como origen del despliegue.
  3. Conecta el repositorio con Netlify o Vercel, plataformas de hosting gratuito. Detectan el proyecto y generan una URL pública.
  4. Configura tu dominio personalizado desde el panel correspondiente. Así la dirección coincide con tu marca.

Resultado esperado: el catálogo carga desde el nuevo dominio y sigue leyendo los datos de tu URL Exec.

Errores frecuentes y solución de problemas

Casi todos los fallos de este proyecto vienen de cuatro causas: permisos, formato del teléfono, tamaño de las imágenes o columnas alteradas en la hoja.

Tabla de diagnóstico

Error o problema Causa probable Solución paso a paso
La web carga vacía o dice «Error de conexión» La URL Exec no tiene permisos para «Cualquiera». Ve a Apps Script > «Implementar» > «Administrar implementaciones». Edita el acceso y cámbialo a «Cualquiera». Guarda y copia la nueva URL.
No se pueden crear tablas automáticas No se ejecutó la función de inicialización. En Apps Script, selecciona inicializarBaseDeDatos en el menú superior y pulsa «Ejecutar». Autoriza los permisos.
Las imágenes cargadas no se ven en la web Las fotos subidas a Google Drive están privadas. El backend debe otorgar permiso público a la carpeta de almacenamiento de fotos. Verifica que las fotos tengan permiso de visualización pública.
El botón de WhatsApp no abre la aplicación El número tiene guiones, espacios o le falta el código de país. En Administración > Ajustes, escribe el número en formato internacional puro, sin signos ni espacios.
El PDF no incluye las fotos de los productos Incompatibilidad de formato de imagen en la conversión a PDF. Envía un prompt de corrección en AI Studio pidiendo que la generación de PDF renderice las imágenes en formato Base64 dentro del documento de impresión.

Errores que debes evitar desde el principio

  • No cambiar el acceso de Apps Script a «Cualquiera»: provoca que la página web no pueda cargar los productos.
  • Subir fotos de producto en formatos pesados (más de 5 MB): ralentiza la carga en teléfonos móviles.
  • Escribir el número de WhatsApp con guiones o espacios: impide que se abra la aplicación al pulsar realizar pedido.
  • Borrar las columnas generadas en Google Sheets: alterar los encabezados destruye la conexión con la API.
  • Olvidar las credenciales de administración: obliga a reiniciar la tabla de Usuarios desde Apps Script.

Cómo pedir una corrección a Gemini

Cuando algo falle en la interfaz, no empieces de cero. Describe el síntoma con precisión en el mismo espacio de AI Studio. Ejemplo de prompt de corrección para el problema del PDF:

Ajusta la función de generación de PDF para renderizar imágenes en formato Base64
directamente en el documento de impresión.

Otros prompts útiles:

  • La web no muestra los productos: revisa la llamada a la URL Exec y muestra un mensaje de error claro si la respuesta falla.
  • El botón de WhatsApp no incluye el total: corrige el cálculo y el formato del mensaje.
  • Agrega paginación de 20 productos por consulta a la API de Apps Script.

Consejo: incluye siempre el mensaje de error exacto que ves en pantalla. Cuanto más concreto sea el síntoma, más útil será la corrección.

Límites y advertencias

  • Almacenamiento de Drive: la capa gratuita de Google ofrece 15 GB. Una foto de producto optimizada pesa alrededor de 500 KB, lo que permite miles de imágenes antes de necesitar espacio adicional.
  • Rendimiento con muchos productos: si el catálogo supera los 1.000 productos, conviene añadir paginación o carga diferida.
  • Modelos de IA: los nombres y la disponibilidad de modelos cambian. Si el modelo citado no aparece, usa el multimodal disponible.
  • Servicios gratuitos: las cuotas de las capas gratuitas pueden variar con el tiempo. Verifica las condiciones actuales antes de un lanzamiento con mucho tráfico.

Resumen general

Este tutorial ha mostrado cómo diseñar, desarrollar y publicar un catálogo interactivo estilo Instagram con herramientas gratuitas, combinando la capacidad multimodal de Gemini con la simplicidad de Google Sheets como base de datos.

El flujo en una frase

Inspiración en Pinterest → backend en Apps Script con el Prompt N.º 1 → frontend en AI Studio con el Prompt N.º 2 y la URL Exec → administración desde Google Sheets → publicación en un subdominio gratuito o en GitHub + Netlify/Vercel.

Con ese flujo, una persona sin conocimientos técnicos puede lanzar una plataforma de ventas con carrito, pedidos directos por WhatsApp, exportación a PDF y panel de administración completo.

Conceptos clave

  • Gemini + Google AI Studio: entorno de desarrollo guiado por IA para crear aplicaciones web a partir de prompts y maquetas visuales.
  • Google Sheets + Apps Script: dúo tecnológico que actúa como base de datos sin coste y API del servidor.
  • URL Exec: dirección pública que conecta la base de datos con la interfaz de usuario.
  • Catálogo estilo Instagram: interfaz dinámica basada en componentes visuales familiares (feed, tarjetas, me gusta, carrusel y perfil).
  • Conversión directa: redireccionamiento del carrito hacia mensajes estructurados de WhatsApp.

Preguntas frecuentes (21 preguntas)

Nivel básico

1. ¿Necesito saber programar para crear este catálogo?

No. Gemini genera el 100 % del código, tanto del backend (Apps Script) como del frontend (interfaz web). Tu trabajo consiste en copiar, pegar y seguir instrucciones en lenguaje natural.

2. ¿Tiene algún costo mensual mantener este catálogo en línea?

Según la fuente, es 100 % gratuito: Google Sheets, Apps Script, Drive y el hosting de Google AI Studio ofrecen capas gratuitas suficientes para miles de visitas al mes. Las cuotas pueden cambiar con el tiempo.

3. ¿Qué sucede cuando cambio un precio en Google Sheets?

Se actualiza automáticamente en la página web. Al refrescar el catálogo, la API lee los datos en tiempo real desde la hoja de cálculo.

4. ¿Los clientes necesitan instalar alguna aplicación?

No. Es una aplicación web responsive que se abre directamente en el navegador del teléfono (Chrome, Safari, Firefox) mediante un enlace o un código QR.

5. ¿Puedo usar mi propio logotipo y colores de marca?

Sí. Desde el panel de administración puedes subir tu logotipo, la foto de portada y definir los colores primarios y las fuentes tipográficas.

6. ¿Dónde se guardan las fotos que subo de mis productos?

Se almacenan de forma automática en una carpeta dedicada dentro de tu cuenta personal de Google Drive.

7. ¿Cómo recibe el vendedor los pedidos de los clientes?

Al pulsar «Enviar pedido», la web abre la aplicación de WhatsApp del cliente con un mensaje preescrito que detalla productos seleccionados, cantidades, precios y total.

Nivel avanzado

8. ¿Qué es la URL Exec y por qué es fundamental?

Es la dirección web que convierte tu Google Sheets en una API. Sin esta URL, la interfaz visual no puede comunicarse con la base de datos.

9. ¿Por qué es obligatorio configurar el acceso de Apps Script como «Cualquiera»?

Porque si se configura como «Solo yo», únicamente tú podrías ver los productos estando conectado con tu cuenta de Google. Al marcar «Cualquiera», la web del catálogo queda abierta al público.

10. ¿Cómo se protege el panel de administración?

El backend utiliza autenticación por token y resguarda las contraseñas en la hoja mediante un algoritmo hash.

11. ¿Puedo organizar mis productos por categorías personalizadas?

Sí. Puedes crear categorías ilimitadas (entradas, postres, promociones…) y asignar cada producto a la correspondiente.

12. ¿Qué ocurre si supero el límite de almacenamiento de Google Drive?

La capa gratuita de Google otorga 15 GB. Una foto optimizada pesa unos 500 KB, lo que permite almacenar miles de imágenes antes de requerir espacio adicional.

13. ¿Cómo funciona el carrusel de fotografías por producto?

En la ficha del producto puedes subir una imagen principal y hasta cuatro secundarias. La interfaz generada por Gemini las organiza en una barra deslizante interactiva.

14. ¿Es posible aplicar descuentos por tiempo limitado?

Sí. El sistema permite ingresar precio regular, precio promo, un texto de etiqueta (por ejemplo «30 % OFF») y una fecha de expiración para mostrar la oferta.

Nivel PRO

15. ¿Cómo puedo conectar un dominio personalizado?

Exporta el código HTML/JS/CSS desde Google AI Studio, súbelo a un repositorio en GitHub y despliégalo gratis en Vercel o Netlify asignando tu DNS personalizado.

16. ¿Qué hago si la compilación en AI Studio tarda demasiado o se detiene?

Asegúrate de utilizar el modelo recomendado, reduce el tamaño de la imagen de referencia (máximo 2 MB) y simplifica la instrucción inicial.

17. ¿Cómo soluciono problemas de rendimiento con más de 1.000 productos?

Implementa paginación o carga perezosa (lazy loading) solicitándolo a Gemini con un prompt del tipo: «Agrega paginación de 20 productos por consulta a la API de Apps Script».

18. ¿Qué ventajas tiene migrar el backend a una base de datos NoSQL?

Permite conexiones en tiempo real, mayor velocidad de respuesta ante solicitudes simultáneas y manejo de millones de registros sin las limitaciones de filas de Sheets.

19. ¿Cómo optimizo las fotos PNG para que la web cargue rápido en móvil?

Pide a Gemini que incorpore una función de compresión automática del lado del cliente utilizando un elemento Canvas HTML5 antes de enviar la imagen a Google Drive.

20. ¿Es posible integrar pasarelas de pago como Stripe o Mercado Pago?

Sí. Se puede solicitar a Gemini en AI Studio que agregue el SDK de Mercado Pago o Stripe Checkout en la ventana flotante de la bolsa de compras antes de derivar a WhatsApp.

21. ¿Qué seguridad se aplica contra inyecciones de código en Google Sheets?

El código Apps Script generado sanitiza las entradas de texto en las consultas y utiliza codificación JSON estricta al devolver los datos a la interfaz visual.

Glosario de términos

  • API (Application Programming Interface): mecanismo de comunicación entre dos sistemas de software.
  • Backend: servidor y base de datos donde se procesa y almacena la información de la tienda.
  • Frontend: la interfaz gráfica con la que interactúa el usuario o cliente final.
  • Google AI Studio: entorno de desarrollo para prototipar aplicaciones impulsadas por los modelos Gemini de Google.
  • Google Apps Script: lenguaje basado en JavaScript que permite automatizar tareas en Google Workspace.
  • Protección hash: algoritmo matemático que convierte una clave de acceso en una secuencia protegida e irreversible.
  • No-Code / Low-Code: metodología de creación de software que minimiza o elimina la escritura manual de código.
  • Prompt: texto con instrucciones detalladas entregado a un modelo de lenguaje para generar un resultado específico.
  • Responsive: diseño web adaptable a la pantalla de cualquier dispositivo.
  • URL Exec: enlace ejecutable de una aplicación web creada con Google Apps Script.
